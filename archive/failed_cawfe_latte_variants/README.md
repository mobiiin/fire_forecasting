# Archived failed CAWFE-Latte variants

These variants were experimental CAWFE-Latte v1.1/v1.2/v1.3 implementations.

They were archived because they produced poor validation mask generalization compared with the original CAWFE-Latte v1.

They are not active architectures and are not registered in `model_factory`.

They may be revisited later, but future work should reintroduce changes progressively, one isolated change at a time.

Active CAWFE-Latte architecture after cleanup:

- `cawfe_latte`

Archived materials are organized as:

- `src_models/` — snapshot of the model file before cleanup
- `configs/` — archived failed variant experiment configs
- `scripts/` — archived failed variant Slurm scripts
- `tests/` — archived failed variant tests
- `docs/` — reserved for related archived notes
